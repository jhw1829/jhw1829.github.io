# hyeonu-rclone website

Static GitHub Pages website for the personal hyeonu-rclone OAuth application.

Review the privacy policy to confirm that it matches your actual rclone usage before publishing.

## Publish
1. Create a public GitHub repository named `jhw1829.github.io` under account `jhw1829` (or use it if already present).
2. Upload `index.html` and `privacy.html` to the repository root.
3. In Settings > Pages, choose Deploy from a branch, `main`, `/(root)`.
4. Verify `https://jhw1829.github.io/` and `https://jhw1829.github.io/privacy.html` work.
5. Enter these URLs in Google Auth Platform > Branding. Google may require domain ownership verification or scope verification; GitHub Pages alone does not guarantee approval.
