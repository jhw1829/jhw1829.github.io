Privacy Policy

Application: hyeonu-rclone
Operator: Hyeonu Jo
Last updated: October 27, 2026

Overview

hyeonu-rclone is a personal, non-commercial setup using rclone to access the operator's own Google Drive from a private Ubuntu user account for research data analysis.

Google user data accessed

With the account owner's consent, rclone may list file metadata, read file contents, create files, update files, and delete files within the authorized Google Drive, depending on the commands the owner executes.

Use of data

Data is used only for the owner's research workflows, including reading datasets and storing analysis outputs. Data is not used for advertising, profiling, or sale.

Storage and security

Google Drive content remains in the owner's Google Drive unless the owner explicitly transfers or processes it. rclone may temporarily buffer or cache file content on the Ubuntu server. OAuth credentials are stored in the user's rclone configuration on the server. This public website does not receive or store OAuth tokens or Drive content.

Sharing

No Google user data is sold or intentionally shared with third parties by this configuration. Data may be processed by Google Drive and the operator's Ubuntu server as needed for the owner's requested operations.

Retention and deletion

The account owner controls local output files and temporary caches, can revoke OAuth access through Google Account permissions, and can remove local rclone credentials. Drive files are retained or deleted according to the owner's actions.

Changes

This policy will be updated if the configuration's data handling changes.

Contact

For questions, contact the operator through the GitHub profile.
